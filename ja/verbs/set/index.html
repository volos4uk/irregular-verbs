「set」の活用：set – set – set

動詞「set」（設定する）は不規則動詞です。過去形は「set」、過去分詞は「set」です。

原形（V1）
set
/sɛt/
過去形（V2）
set
/sɛt/
過去分詞（V3）
set
/sɛt/

意味

設定する

to put something in its place

例文

I set an alarm for six o'clock.

パターン

AAA — 3つの形がすべて同じ
